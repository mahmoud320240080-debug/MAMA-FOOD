# Credits

## Lottie animations (`src/assets/lottie/`)

All five animations are original work made for MAMA FOOD. They are generated by
[`scripts/build-lotties.mjs`](scripts/build-lotties.mjs) in the brand colors
(red `#ED1B24`, yellow `#FFDE17`, brown `#2B1B17`, cream `#FFFBEA`, taken from `src/lib/brandColors.js`). No third-party
animation files are used, so there are no attribution or license restrictions. They
belong to the project and can be used commercially.

To change one, edit the script and run `node scripts/build-lotties.mjs`.

| File | Used for | Source | License |
|---|---|---|---|
| `empty-cart.json` | Empty cart (cart drawer) | Original, `scripts/build-lotties.mjs` | Project-owned |
| `no-orders.json` | No orders yet / no orders for a day / no addons (admin) | Original, `scripts/build-lotties.mjs` | Project-owned |
| `no-meals.json` | A day with no meals (customer home, admin weekly menu) | Original, `scripts/build-lotties.mjs` | Project-owned |
| `no-results.json` | No search/filter results (admin orders, meals, add-meal search) | Original, `scripts/build-lotties.mjs` | Project-owned |
| `not-found.json` | 404 page | Original, `scripts/build-lotties.mjs` | Project-owned |
